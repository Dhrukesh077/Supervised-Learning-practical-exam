# Data
`train.csv` — Ames Housing training file (1,460 rows × 81 columns) from the Kaggle competition
[House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).
Per the exam, only `train.csv` is used (own 80/20 split, `random_state=42`). `test.csv` / `sample_submission.csv` are not needed.
The file is git-ignored; download it from Kaggle if you clone the repo.
